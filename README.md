# Flowboard

Tablica przepływu ekranów: zrzuty, notatki i ramki tekstowe połączone strzałkami.

- Przeciągnij obrazy na tablicę — zapisują się od razu.
- Notatki (kolorowe, tekst wyśrodkowany i skalowany) oraz ramki ze zwykłym tekstem.
- Strzałki lądują w miejscu upuszczenia na krawędzi i zostają tam po przesunięciu kart.
- Eksport ZIP z opisem przepływu dla programisty.
